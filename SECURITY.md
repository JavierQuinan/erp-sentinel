# Security policy

ERP Sentinel is pre-release and currently has no supported production release. Report vulnerabilities privately using GitHub private vulnerability reporting if enabled, or contact the maintainer through GitHub to establish a private channel before sharing details. Do not post exploit details or customer data in public issues. Include affected version, impact, reproduction in an authorized test environment and suggested mitigation if available. Never submit credentials or personal data. Acknowledgement and remediation targets will be defined before the first release.
