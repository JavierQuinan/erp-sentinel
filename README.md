# ERP Sentinel

Open-source security, auditing and AI governance framework for enterprise ERP systems. Odoo-first, extensible by design.

**Status: planning / pre-alpha. No functional scanner or production release yet.**

## Initial scope
A local, deterministic security scanner for Odoo 18 Community custom addons, with actionable findings and machine-readable reports. Runtime access verification and AI governance are future phases.
