# ERP Sentinel
Open-source ERP security assurance, auditing and AI governance framework. Odoo-first, extensible by design.

**Status: planning / pre-alpha. No functional scanner, runtime engine or production release yet.**

Initial focus: policy-as-code, effective authorization and security regression testing in isolated Odoo 18 Community labs. Existing static analysis engines may be integrated after competitive and license validation. Differentiation remains a hypothesis.
